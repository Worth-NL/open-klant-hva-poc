1. Python dependency installation: pygraphviz
------------------------------------------------

Command:
    pip install -r requirements/dev.txt

Error:
    Building wheel for pygraphviz (pyproject.toml) ... error
    fatal error: graphviz/cgraph.h: No such file or directory
    compilation terminated.
    error: command 'x86_64-linux-gnu-gcc' failed with exit code 1
    ERROR: Could not build wheels for pygraphviz, which is required to install

Cause:
    The Graphviz native development headers were not installed. The Python
    package needs graphviz/cgraph.h to compile its extension.

    sudo apt install graphviz libgraphviz-dev

    /mnt/c/Program Files/nodejs/npm

Resolution:
    Install and use Linux Node.js 24 through nvm, as pinned by .nvmrc:

    source ~/.bashrc

    nvm use 24

    npm run build

3. Django migration: PostgreSQL local socket unavailable
----------------------------------------------------------

Command:
    python src/manage.py migrate

Error:
    django.db.utils.OperationalError: connection is bad: connection to server
    on socket "/var/run/postgresql/.s.PGSQL.5432" failed:
    No such file or directory
    Is the server running locally and accepting connections on that socket?

Cause:
    Development settings used an empty DB_HOST, which makes PostgreSQL use the
    local Unix socket. PostgreSQL was running in Docker rather than locally.

Resolution:
    The Docker database was published on port 5432 and .env was configured with:

    DB_HOST="127.0.0.1"
    DB_PORT="5432"
    DB_USER="openklant"
    DB_NAME="openklant"

    The migration then completed with:
    Running migrations:
      No migrations to apply.

Status: Resolved.


4. Docker web-init: duplicate UUID during migration 0049
-----------------------------------------------------------

Command:
    docker compose up -d

Error:
    service "web-init" didn't complete successfully: exit 1

    psycopg.errors.UniqueViolation: could not create unique index
    "klantinteracties_internetakenactorenthoughmodel_uuid_key"
    DETAIL: Key (uuid)=(748cd831-fff0-4d08-9cbe-813a902558e0) is duplicated.

    django.db.utils.IntegrityError: could not create unique index
    "klantinteracties_internetakenactorenthoughmodel_uuid_key"
    DETAIL: Key (uuid)=(748cd831-fff0-4d08-9cbe-813a902558e0) is duplicated.

Cause:
    The persisted development database was at migration 0048, while the pulled
    Docker image contained migration 0049. That migration added unique UUID
    fields to existing tables, and the add-field operation produced duplicate
    values in the existing database.

Resolution:
    The three UUID columns were added with PostgreSQL-generated UUID values and
    unique constraints. Migration 0049 was then marked as already applied:

    docker compose run --rm --no-deps --entrypoint sh web -c \
        "python /app/src/manage.py migrate klantinteracties 0049 --fake"

    The database volume was preserved; it was not deleted or reset.

Status: Resolved. Docker services became healthy afterward.
